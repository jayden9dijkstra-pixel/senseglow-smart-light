
- Private MCP tools (orders, sales, funnel, attribution, ads) query with the caller's OAuth token and require the admin role; why: database RLS stays the single access boundary and no service key is used in MCP.
- Dashboard metrics live as pure functions in src/lib/dashboardMetrics.ts (tested with vitest); edge functions only return raw, PII-free data; why: one tested source of truth for margin, levy and VAT rules.
- Shopify orders sync into shop_orders via supabase/functions/_shared/shopify-orders.ts (cron every 5 min + on dashboard load) and never overwrite stored attribution with empty values; why: attribution is irreplaceable once lost.
- Google Ads daily stats arrive via the ingest-ads function (x-ingest-token = ADS_INGEST_TOKEN) from a Google Ads Script; why: the connector gateway cannot be called from edge functions.
- Dashboard traffic filtering uses `exclude_internal`; reserve `intern` for explicit device marking commands so report filters never change visitor classification.
- Google Ads server conversions are appended to a Google Sheet (service-account JWT, _shared/google-sheets.ts) from the order sync, deduped via ads_conversion_exports and only for orders with recorded ad consent; why: Google Ads imports the Sheet and the connector gateway cannot be used from edge functions.
- Ad angles (?a=), kits and use cases live as data in src/lib/angles.ts and are reused by the page and scripts/prerender.ts; kit prices come from Shopify automatic discounts, so the cart drawer shows Shopify's own discount lines via a preview cart; why: one source for copy, and Shopify stays the single source of prices.
- Search-intent landing pages are data in src/lib/landingPages.ts (NL only, no hreflang) and rendered by both src/pages/LandingPage.tsx and scripts/prerender.ts; why: one source so server HTML and the live page never diverge.
- Legal/info page bodies live in src/pages/content/*Content.tsx (no layout imports) and scripts/prerender.ts renders them plus the businessInfo footer line into server HTML; cookie choice encoding lives in src/lib/consent.ts; why: one source for client and server HTML, and no asset imports in the prerender.
